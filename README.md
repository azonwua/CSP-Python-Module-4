# CSP-Python-Module-4
Weather Reporter
Description

This project is a command-line weather application written in Python. It asks the user to enter a city, retrieves live weather information from the OpenWeatherMap API, displays the information, and saves it to a CSV file.

Features

Asks the user for a city name.

Checks that the city name is not empty.

Retrieves live weather data from OpenWeatherMap.

Displays the city, country, temperature, humidity, and weather description.

Saves the weather information to city_data.csv.

Reads the CSV file and displays the number of cities and their temperatures.

Requirements


How to Run

Save the program as reporter.py.

Add your OpenWeatherMap API key to the program.

Open a terminal in the project folder.

Run:

python reporter.py


Enter a city name when prompted.

Files

reporter.py — The main Python program.

city_data.csv — Stores the weather information retrieved from the API.

README.md — Contains information about the project.
